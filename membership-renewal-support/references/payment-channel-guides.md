# 支付渠道关闭路径与特殊问题指引

## App 内通用入口

- 汽水音乐 App → 我的 → 会员中心 → 套餐续费信息 → 取消续费

适用说明：

- 用户还能登录原账号时，优先引导走 App 内入口

## 各支付渠道关闭路径

### 支付宝

- 支付宝 App → 我 → 设置 → 支付设置 → 免密支付/自动扣款 → 选择汽水音乐 → 关闭服务

### 抖音支付

- 抖音 App → 我 → 右上角三横线 → 我的钱包 → 设置 → 自动扣款/免密支付 → 选择汽水音乐 → 关闭

### 微信

- 微信 App → 我 → 服务 → 钱包 → 支付设置 → 自动续费 → 选择汽水音乐 → 关闭

### 苹果订阅

- App Store → 头像 → 账户 → 订阅 → 选择汽水音乐 → 取消订阅

## Apple 特殊问题

### iPhone 用户反馈页面无法跳转或打不开

> 如果页面无法打开，您可以尝试手动操作：手机设置 → Apple ID → 订阅 → 选择汽水音乐 → 取消订阅。

### iPhone 用户反馈订阅中没有汽水音乐

> 请确认当前登录的 Apple ID 是否为购买会员时使用的账号。如果更换过 Apple ID，需要切换回原购买账号后在订阅列表中取消。如无法确定原 Apple ID，建议拨打 400-666-8800 联系苹果客服协助排查。

### 苹果换安卓后无法取消

> 苹果订阅需在 Apple 系统环境中管理。您可以使用此前的 iOS 设备，通过“手机设置 → Apple ID → 订阅 → 选择汽水音乐 → 取消订阅”关闭。如已无 iOS 设备，可拨打 400-666-8800 联系苹果客服，说明情况后请求关闭订阅。
