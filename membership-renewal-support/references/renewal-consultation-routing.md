# 自动续费与扣费咨询分流

适用于以下问题：

- 为什么会自动续费
- 已关闭自动续费但仍被扣款
- 未收到续费通知
- 扣款日早于展示续费日
- 续费支付方式与首次购买不同
- 延迟扣费 / 到期后仍被扣款

## 第一步：排除不适用场景

若用户明确提及“退款 / 退钱 / 不想要 / 投诉”等诉求，不在本场景处理，应转“会员退款”。

## 第二步：常用诊断字段

- `{账号_会员信息_新系统_续费状态}`
- `{账号_会员信息_新系统_当前会员状态}`
- `{账号_自动续费通知_是否发送}`
- `{账号_会员_历史订阅信息}`
- `{账号_会员_昵称_同设备}`

说明：

- 原始资料中提到部分补充信息“暂时无法在飞书文档外展示”，遇到缺失数据时应按内部流程补查，不要自行补写。

## 场景一：咨询为何自动续费

处理动作：

- 说明平台不会主动扣款，仅在用户开启自动续费后才会扣费
- 提供历史订单和续费状态查看入口
- 若当前仍在续费中，继续给关闭指引

基础话术：

> 您好，平台不会主动发起扣款，只有在您开启了自动续费服务后才会进行自动续费哦～您可以前往汽水音乐 App → 我的 → 会员中心 → 管理套餐续费信息，查看历史购买订单和自动续费状态。

追加判断：

- 若 `renewstatus` 为已解约 / `-` / 空，且 `vipstatus` 为 `vip` / `svip`：

> 您的自动续费服务已经是关闭状态啦，当前会员仍可使用到「对应会员类型的 end_time」哦，可别浪费了！

- 若 `vipstatus` 为 `free_vip`：

> 您这个账号是免费会员，没有开启自动续费服务哦～您的免费会员可以使用到「free_vip 的 end_time」。

- 若 `renewstatus` 为 `续费中`：

> 已为您查询到，您的自动续费目前是开启状态。若您想关闭，可以前往汽水音乐 App → 我的 → 会员中心 → 套餐续费信息，点击取消续费并按页面提示关闭。安卓用户稍等片刻后可直接关闭；苹果用户会跳转至订阅界面，在订阅列表中选择「汽水音乐」后取消订阅即可。为了保护您的支付安全，需要您自己手动完成关闭，小助手无法代为操作哦～

- 若 `{账号_会员_昵称_同设备}` 不为空：

> 另外，您的设备上还登录过昵称为「{账号_会员_昵称_同设备}」的会员账号。如果您收到预期外的扣费订单，也可能是这个账号在扣费，您可以一并留意一下～

## 场景二：已关闭自动续费但仍被扣款

### 情况 A：用户未解约成功

命中条件：

- `{账号_会员信息_新系统_续费状态} = 续费中`

话术：

> 系统记录您的自动续费服务还未关闭。您可以前往汽水音乐 App → 我的 → 会员中心 → 套餐续费信息，点击取消续费并按页面提示关闭。安卓用户稍等片刻后可直接关闭；苹果用户会跳转至订阅界面，在订阅列表中选择「汽水音乐」后取消订阅即可。为了保护您的支付安全，需要您自己手动操作，小助手无法代为关闭哦～

### 情况 B：解约时间晚于扣款时间

命中条件：

- `{账号_会员信息_新系统_续费状态} = 已解约`
- `{账号_会员_历史订阅信息-解约时间是否在自动扣款时间之后} = 解约时间在自动扣款时间之后`

话术：

> 系统是按您的订阅计划扣款后，才收到了您的关闭指令哦～这次扣款时间是「最近一笔成功订单的 paid_time」，您关闭自动续费的时间是「{账号_会员_历史订阅信息-最近一笔订阅的解约时间}」。不过请放心，您的自动续费现在确实已经关闭了，之后不会再扣啦～

### 情况 C：疑似其他账号在扣费

命中条件：

- `{账号_会员信息_新系统_当前会员状态} = free / free_vip`
- `{账号_会员_昵称_同设备}` 中存在 `is_auto_paid = 是` 的 uid

话术：

> 帮您查询到，您还有另外一个昵称为「{账号_会员_昵称_同设备}」的账号目前是会员状态，会不会是这个账号在扣费呀？您可以切换登录这个账号看看哦～

## 场景三：未收到续费通知

处理动作：

- 调用 `{账号_自动续费通知_是否发送}` 查询通知记录

### 若已发送通知

> 关于续费通知，我查询到系统已在「{账号_自动续费通知_是否发送-续费通知发送的时间}」通过汽水音乐或抖音站内信为您发送过续费提醒了哦，您可以在汽水音乐 → 我的 → 右上角铃铛中查看。

### 若进一步核实到站内信已被删除

> 经核实，平台已为您发送过续费站内信，同时记录显示站内信后来被删除。辛苦您确认一下，是否有家人或朋友登录过您的账号并误删了消息～

### 若未发送通知

内部处理：

- 此情况对用户不可见
- 外部流转并触发转人工

对外话术：

> 哎呀，查到您最近确实没有收到续费通知，这边先向您致歉。为了尽快帮您核实，我马上为您转给相关同事进一步处理。

### 若最近一笔订单为主动购买

> 我看到您最近的一笔订单是主动购买的会员，不是自动续费哦。这种情况下，支付渠道会给您发扣款凭证，而我们的站内信续费通知是针对下一次自动续费用户发送的～

## 场景四：扣款日早于展示续费日

### 情况 A：上次扣费 0 / 0.01 / 1 元，本次扣费 8 / 15 元，间隔 5-7 天

> 您好，这可能是您参与了「1 元试用 7 天」体验卡活动。商品购买页面会说明 7 天卡到期后将自动续费连续包月业务，因此产生了这笔扣费哦～

### 情况 B：两次扣费间隔 28-30 天

> 您好，为了保证您的会员权益，平台会在每个计费周期开始前 24 小时（支付宝、抖音支付）或 48 小时（微信支付）自动扣费。不过请放心，您的会员权益仍然是按原周期计算，不会因为提前扣费而提前结束～

## 场景五：续费支付方式与首次购买不同

处理方式：

- 用户反馈自动续费使用了与首次购买不同的支付方式时，引导咨询抖音支付扣费顺序

话术：

> 您好，关于抖音支付的扣费顺序问题，辛苦您联系抖音客服进一步咨询。联系路径：抖音 App → 我 → ≡ → 我的钱包 → 右上角客服耳麦。热线电话：95766 转 1，服务时间为每天 8:00-24:00。

## 场景六：延迟扣费 / 到期后仍被扣款

### 情况 A：苹果支付，中途未扣款，次月或延迟后才扣款

> 您好，出现这个情况，可能是中途有余额不足等原因导致未续费成功，后续余额充足后系统会再次尝试扣费。具体情况建议您拨打 400-666-8800 联系苹果人工客服咨询哦～

### 情况 B：支付宝 / 抖音支付，到期后仍被扣款

内部背景：

- 自动扣款第一次失败后，支付宝可延长 7 天、抖音支付可延长 30 天进行重试

对外话术：

> 您好，出现这个情况，可能是中途有余额不足等原因导致未续费成功，后续余额充足后会再次扣费哦～
