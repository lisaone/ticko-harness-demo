# 自动续费取消失败分流

适用于以下问题：

- 在 App 内找不到关闭自动续费入口
- 声称已经关闭，但仍然被扣款
- 因账号注销、封禁、更换设备等原因，无法按原路径关闭

## 场景一：免费体验会员不会产生续费

命中条件：

- `{账号_会员信息_新系统_续费状态} = 已解约 / - / 空`
- `{账号_会员信息_新系统_当前会员状态} = free_vip`

话术：

> 您好，已为您核实，您当前是免费体验会员，到期后不会自动产生续费扣款，请您放心。

## 场景一 A：扣款发生在解约之前，属于正常续费

命中条件：

- `{账号_会员信息_新系统_续费状态} = 已解约 / - / 空`
- `{账号_会员信息_新系统_当前会员状态} = vip / svip`
- `{账号_会员_昵称_同设备} = 为空 / []`
- `{账号_会员_历史订阅信息-解约时间是否在自动扣款时间之后} = 是`

话术：

> 您好，已为您排查到，本次扣款时间为「最近一笔成功订单的 paid_time，格式：YYYY-MM-DD HH:MM」，您关闭自动续费的时间为「{账号_会员_历史订阅信息-最近一笔订阅的解约时间}」。系统是按您的订阅计划完成扣款后才收到关闭指令的，本次扣款属于正常续费哦。请放心，您的自动续费现在已经关闭，之后不会再自动扣费了～

## 场景一 B：当前账号无会员及续费服务

命中条件：

- `{账号_会员信息_新系统_续费状态} = 已解约 / - / 空`
- `{账号_会员信息_新系统_当前会员状态} = free`
- `{账号_会员_昵称_同设备} = 为空 / []`

话术：

> 您好，已为您查询到，您当前账号目前无会员及自动续费服务，请放心，不会产生续费扣费哦。如果您确认有扣款记录，辛苦您提供一下扣款订单截图，我们进一步帮您核查～

## 场景一 C：已解约仍被扣款，属于异常

命中条件：

- `{账号_会员信息_新系统_续费状态} = 已解约 / - / 空`
- `{账号_会员信息_新系统_当前会员状态} = vip / svip`
- `{账号_会员_昵称_同设备} = 为空 / []`
- `{账号_会员_历史订阅信息-解约时间是否在自动扣款时间之后} = 否 / 记录异常`

处理动作：

- 索要扣款订单截图
- 记录扣款时间、渠道、金额
- 外部流转至产品/财经侧，按“取消自动续费后仍扣款”流程处理

话术：

> 您好，已为您核实，当前记录显示您已关闭自动续费，但仍出现扣款，情况需要进一步核查。辛苦您提供扣款订单截图，并补充扣款时间、渠道和金额，我们会按“取消自动续费后仍扣款”流程为您继续处理。

说明：

- 原始资料中这一段附带的话术与“正常续费”场景重复，这里已按处理动作改写为异常场景话术。

## 场景二：同设备其他账号在扣费

命中条件：

- `{账号_会员信息_新系统_续费状态} = 已解约 / - / 空`
- `{账号_会员信息_新系统_当前会员状态} = free 或 vip / svip`
- `{账号_会员_昵称_同设备} = 不为空 / []`

话术：

> 您好，已为您核实，当前扣费可能来自同设备上的其他账号。若您可以登录该账号，建议切换登录后在汽水音乐 App 内关闭续费；若暂时无法登录，也可以直接在对应支付渠道内关闭自动扣款。

追加引导：

- 若用户可以登录该账号：汽水音乐 App → 我的 → 会员中心 → 套餐续费信息 → 取消续费
- 若用户无法登录：读取 `payment-channel-guides.md`

## 场景三：当前仍在续费中，需要引导关闭

命中条件：

- `{账号_会员信息_新系统_续费状态} = 续费中`

基础话术：

> 您好，已为您核实，当前会员服务仍处于自动续费中，需要您在对应支付渠道中手动关闭。若您告诉我本次扣费是通过支付宝、微信、抖音支付还是苹果订阅开通的，我可以继续给您对应的关闭路径。

补充说明：

- iPhone 页面打不开、订阅列表中没有汽水音乐、苹果换安卓、要求客服代操作等情况，统一读取 `payment-channel-guides.md`

## 建议判定顺序

1. `renewstatus = 续费中` 时，优先判为场景三
2. 已解约且存在同设备其他账号时，优先判为场景二
3. 已解约且用户反馈被扣款时，再区分场景一 A / 一 C
4. 其余已解约状态，再判断是否属于 `free_vip` 或 `free`
