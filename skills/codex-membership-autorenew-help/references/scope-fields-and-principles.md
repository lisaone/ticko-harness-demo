# 适用范围、查询字段与总体原则

## 1. Skill 目标

处理以下问题：

- 用户咨询自动续费规则
- 用户咨询如何关闭自动续费
- 用户反馈无法关闭自动续费
- 用户反馈“已经关闭但仍被扣款”
- 用户反馈未收到续费通知
- 用户咨询扣款时间、展示续费时间、支付方式变化、延迟扣费等与自动续费相关的问题

不处理以下问题：

- 用户明确提出“退款 / 退钱 / 投诉 / 赔偿”等交易售后诉求
- 用户反馈“扣款成功但会员时长 / 权益未到账”
- 用户仅咨询会员权益区别
- 用户反馈播放、下载等其他产品功能异常

若命中不处理范围，直接结束本 skill，并提示转入对应场景。

## 2. 适用边界

### 2.1 使用条件

满足以下任一情况时使用本 skill：

- 咨询场景：用户咨询续费规则、自动扣费原因、如何取消续费
- 异常场景：找不到关闭入口、取消失败、声称已关闭但仍被扣款、账号无法登录导致无法关闭

### 2.2 禁止使用

出现以下情况时，不使用本 skill：

- 用户明确要求退款、退钱、投诉、申诉交易问题
- 用户反馈扣费成功但会员时长未到账、权益未到账
- 用户只问会员权益差异
- 用户反馈播放、下载等非续费问题

## 3. 查询字段定义

本 skill 依赖以下信息进行判断：

- `{账号_会员信息_新系统_当前会员状态}`
  - 可能值：`free / free_vip / vip / svip`
- `{账号_会员信息_新系统_续费状态}`
  - 可能值：`续费中 / 已解约 / 空`
- `{账号_会员信息_新系统_账号状态}`
  - 可能值：`正常 / 异常`
- `{账号_自动续费通知_是否发送}`
  - 用于判断系统是否发送过续费通知
- `{账号_自动续费通知_续费通知发送时间}`
  - 用于回复通知发送时间
- `{账号_会员_历史订阅信息}`
  - 用于查询最近一笔订阅记录、最近一笔成功订单 `paid_time`、最近一笔订阅的解约时间、订阅渠道等信息
- `{账号_会员_历史订阅信息-解约时间是否在自动扣款时间之后}`
  - 可能值：
    - 解约时间在自动扣款时间之后
    - 解约时间不在自动扣款时间之后
    - 记录异常
- `{账号_会员_昵称_同设备}`
  - 当前设备上曾登录过的其他会员账号昵称列表
- `{账号_会员_昵称_同设备_is_auto_paid}`
  - 用于判断同设备其他账号中是否存在自动续费中的账号

## 4. 总体处理原则

### 4.1 先做场景排除

若用户明确提及以下词语，停止本 skill，转对应场景：

- 退款
- 退钱
- 投诉
- 不想要了
- 赔偿
- 到账异常
- 权益未到账

### 4.2 再判断用户核心意图

用户问题归入以下两类：

- 子场景 A：自动续费与扣费咨询
- 子场景 B：无法关闭自动续费

若用户表达同时涉及两类问题，优先按用户最强诉求回答，并补充另一类指引。
