# 统一回复风格与冲突修正规则

## 1. 统一回复风格要求

- 语气：清晰、安抚、非指责
- 避免说“系统不会出错”“一定是您操作问题”
- 若判断为异常，明确说明“需进一步核查”，不要提前下定论
- 若需要用户操作，必须说明平台无法代操作的原因：账户与支付安全
- 若需要转人工，不暴露内部字段、bug、技术细节

## 2. 冲突修正规则

本 skill 生成时，以本节为准：

1. “已解约仍被扣款异常”与“正常续费”话术原文冲突

- 已修正：异常场景必须索要订单截图并流转，不再复用正常续费话术

2. “已解约 / 空 / -”表达不统一

- 统一为：`已解约 / 空`

3. “用户声称已关闭但仍被扣款”可能同时出现在咨询与无法关闭场景

- 统一处理方式：优先判断当前续费状态，再判断扣款与解约时间先后关系

4. “未看到套餐续费信息”不等于绝对未开通续费

- 对外表述使用“通常说明当前登录账号未开通自动续费”，避免绝对化

5. 内部信息与用户话术分离

- 支付渠道失败后补扣周期、bug、内部流转等内容，不直接透出内部术语
